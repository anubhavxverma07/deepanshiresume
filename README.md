# Deepanshi Portfolio

Static portfolio website — HTML, CSS, JS. No build tools needed.

## Local Preview
Open `index.html` in your browser.

## Deploy to GitHub + Cloudflare Pages

1. Create a new GitHub repo: `deepanshi-portfolio`
2. Upload all files (index.html, style.css, script.js, images/)
3. Go to Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git
4. Select your repo
5. Build settings:
   - Framework preset: **None**
   - Build command: *(leave blank)*
   - Build output directory: `/`
6. Save and Deploy 🚀
